# 한눈 장부

대출 · 할부 · 고정지출 · 취미지출 · 카드 명세를 한 화면에서 보는 개인 장부.

## 실행

- **윈도우** — `장부실행.bat` 두 번 누르기
- **맥** — 터미널에서 한 번만 `chmod +x "장부실행.command"`, 그 뒤로는 두 번 누르기

브라우저가 저절로 열린다. 끄려면 검은 창에서 `Ctrl+C`.

## 내 기록이 어디 있나

이 폴더의 **`장부.json`** 파일 하나가 전부다. 이 폴더가 구글 드라이브 안에 있으니
저장하는 순간 드라이브가 알아서 백업하고 다른 기기로 동기화한다.

저장할 때마다 `backups/` 에 그 시점 사본이 쌓인다(최근 30개). 파일이 깨지면
프로그램이 가장 최근 백업으로 알아서 되살린다.

`장부.json` 은 `.gitignore` 에 들어 있어 깃허브에 올라가지 않는다. **절대 `git add -f` 하지 말 것.**

## 카드 블록은 "다시 보는 창"이다

카드에 따로 적지 않는다. **기둥에 기록하면서 `지출 형식`을 카드로 고르면**
그 카드 블록에 저절로 모인다.

```
할부 블록에 "현대리바트 · 삼성카드" 기록  →  삼성카드 블록에 그 금액이 잡힘
                                      →  카드 합계에도 반영
```

그래서 **기둥 합계와 카드 합계는 서로 겹친다.** 같은 돈을 "어디에 썼나"(기둥)와
"무엇으로 냈나"(카드) 두 각도로 본 것이라 더하면 안 된다. 전체 지출은 기둥 쪽이다.

카드 상세를 열면 어느 기둥에서 얼마를 썼는지, 줄마다 무엇을 샀는지 보인다.
카드에만 직접 적고 싶은 것이 있으면 카드 상세에서 `＋` 로 넣을 수 있다.

## 명세서 자동 읽기 (내 PC판)

카드 명세서를 끌어다 놓으면 표로 옮겨 주는 기능은 **Claude 열쇠**가 하나 필요하다.
브라우저 안에는 AI 가 없어서, 서버가 대신 Anthropic API 를 부른다.

1. https://console.anthropic.com 에서 **API key** 를 만든다
2. 앱에서 `명세서 읽기` → `읽기` 를 누르면 열쇠를 넣으라는 창이 뜬다. 한 번만 넣으면 된다
3. 열쇠는 이 폴더의 `claude_key.txt` 에만 저장된다. **깃허브에 안 올라간다**(`.gitignore`)

비용은 명세서 한 장에 몇 십 원 수준이다. 열쇠를 넣지 않으면 자동 읽기 단추가
`직접 채우기` 로만 동작한다.

> 스캔한 PDF(글자가 없는 사진 PDF)도 읽는다. 카드사가 보내는 명세서는 대개 이런
> 형태라, 글자를 뽑는 대신 페이지를 그림으로 만들어 읽힌다. 비밀번호가 걸린
> PDF 는 비밀번호를 물어본다.

## 폰에서 보기

검은 창에 나오는 `폰·태블릿` 주소를 폰 브라우저에 넣는다. 같은 와이파이여야 하고,
PC가 켜져 있어야 한다. **폰에서는 보기만 되고 고칠 수는 없다** — 터치 기기는
편집 단추가 아예 나오지 않는다.

폰에서도 열려면 실행 파일 안의 마지막 줄을 이렇게 바꾼다.

```
python server.py --lan
```

## 화면을 고칠 때

진짜 원본은 **`src/ui.html`** 하나다. 여기만 고치고 아래를 돌린다.

```bash
python build.py
```

`index.html` 은 만들어지는 파일이라 직접 고치지 않는다(고쳐도 다음 빌드에 지워진다).

같은 `src/ui.html` 이 Claude 아티팩트로도 게시된다. 저장소만 갈아 끼우는 구조라
아티팩트에서는 Claude 저장소를, 여기서는 `장부.json` 을 쓴다.

## 쓰는 법 몇 가지

- **기간** — 기본은 **이번 달**이다. 위쪽 `‹ 2026.09 ›` 로 달을 넘기고, 옆의 `연` 을 누르면
  1년 전체 합계로 바뀐다. 막대그래프의 **막대를 누르면 그 달만** 볼 수 있다.
  화면의 모든 숫자(기둥·카드·구분·사이드바)가 고른 기간만 센다
- **지출 형식** — 기록마다 **현금 / 카드**를 고른다. 카드면 어느 카드사인지까지 남는다.
  카드 명세서로 들어온 줄은 그 카드로 자동으로 잡힌다
- **치료비와 보험 청구** — 기록 창의 `＋ 치료비 · 보험 청구` 를 켜면 병원에 낸 돈과
  보험에서 돌려받는 돈을 따로 적는다. **장부에 실리는 금액은 실제 내 돈**(총액 − 환급)이
  자동으로 계산되고, 금액 칸은 손대지 못하게 잠긴다.
  · 상태는 `미청구 · 청구중 · 받음 · 부지급` 네 가지. 아직 못 받은 돈은 지출이 아니라
    **받을 돈**으로 따로 센다 (사이드바와 대시보드에 잔액이 뜬다)
  · 예상보다 덜/더 받으면 차액을 알려 주고 실제 부담액을 다시 맞춘다
  · 청구해 두고 30일 넘게 소식이 없으면 표시가 붙고, 진료일부터 3년(청구 시효)이
    90일 안쪽으로 다가오면 경고가 뜬다
  · 소액 진료는 공제하고 나면 환급이 0원일 수 있다. 그때는 `미청구` + 예상 0원으로 두면
    전액이 그대로 내 돈으로 잡힌다
- **줄 고치기·복사·지우기** — 표의 **줄을 누르면** 바로 고치기 창이 열린다.
  **오른쪽 클릭**하면 고치기 / 복사 / 지우기 메뉴가 나온다 (지울 때는 한 번 물어본다).
  **복사**는 내용을 그대로 베껴 새 줄을 만들고 금액 칸에 커서를 둔다 — 비슷한 항목을
  줄줄이 넣을 때 쓴다
- **매달 나가는 돈은 손대지 않아도 계속 간다.** 끝나는 날을 비워 두면 끝이 없다
- **할부** — `전체 금액` 과 `개월` 만 넣으면 월 납입액은 자동으로 나뉜다(2,544,000 / 12 →
  월 212,000원). 지난 달에 시작한 할부를 지금 적어도 회차에 맞춰 각 달로 저절로 퍼진다.
  **이자가 붙어 실제로 더 냈다면** 그 달에 낸 금액을 적으면 되고, 자동 계산값보다
  많은 차액을 **이자**로 따로 세어 보여 준다 (장부 줄·기둥 머리·`이자` 타일)
- **할부금 — `첫 회차` 와 `이후 회차` 두 칸으로 넣는다**
  카드사는 전체를 회차로 똑같이 나누지 않고 첫 회차가 나머지를 떠안는다. 그래서 칸이 둘이다.
  · 한쪽을 고치면 다른 쪽이 따라 바뀌고, 아래에 `합계 … 전체 금액과 맞아요` 로 확인해 준다
  · `자동` = 전체를 회차로 고르게 나눈 값 (칸은 잠기지만 값은 그대로 보인다)
  · `직접` = 명세서에 적힌 값. `자동` 을 누르면 언제든 되돌아간다
  · 첫 회차가 0원 이하가 되는 조합은 빨간 글씨로 알리고 **저장을 막는다**
  · **어느 한 달만** 다르면 그 줄에서 우클릭 → `이 달 금액`. **할부는 그 달만 바뀌고
    다음 달은 저절로 자동으로 돌아간다.** 되돌리려면 같은 창의 `자동으로` 를 누른다
  · 할부 기간이 끝난 달에는 아무것도 잡히지 않는다 (12개월이면 12번째 달까지만)
- **달마다 금액이 다를 때** — 전세대출처럼 이율 따라 달라지는 돈은 그 달 금액만 적으면 된다.
  줄에서 **오른쪽 클릭 → `이 달 금액`**. 달과 금액만 넣는 작은 창이 열리고, 지난달과
  얼마나 차이 나는지 바로 보여 준다. **적은 달부터 그 값이 이어지고, 그 전 달 기록은
  손대지 않는다.** 대출·할부·고정지출 어느 기록에나 쓸 수 있다
- 금액이 바뀐 적 있는 줄은 장부 표의 금액 옆에 작은 표시가 붙는다. 고치기 창 안의
  `금액 이력` 에 언제 얼마였는지 쌓이고, 잘못 넣은 이력은 지울 수 있다.
  단순 오타를 바로잡을 때는 금액을 고친 뒤 `처음부터 고치기` 를 고른다
- **날짜는 전부 일까지** 넣는다. 청구일도, 고정지출이 끝나는 날도 날짜로 고른다
- **기둥** — 대출 · 할부 · 고정지출처럼 크게 묶는 칸. 이름과 색을 바꿀 수 있고
  **마우스로 끌어 순서를 바꿀 수 있다**
- **카드 마감일** — 4로 두면 `6.5 ~ 7.4` 를 7월 청구로 잡는다. 카드 타일에 기간이 그대로 보인다
- **할부** — `6/12` 처럼 회차가 칸을 채우며 진행을 보여준다. 다 갚으면 타일에서 사라지고
  검색으로는 계속 찾을 수 있다
- **외화** — 달러·위안으로 적으면 그날 환율로 원화에 합산된다. 환율은 기록할 때 값이
  굳으므로 나중에 기준을 바꿔도 지난 기록은 흔들리지 않는다
- **검색** — `12만`, `>100만`, `3월`, `2026-08`, `완납`, 가맹점 이름 다 된다. `/` 키로 바로 검색창
- **금액 가리기** — 위쪽 눈 모양 단추. 옆에 사람이 있을 때
- **내보내기** — CSV(엑셀용) · JSON(통째로 옮길 때)

## 필요한 것

파이썬 3.9 이상. 그 외에 설치할 것은 없다.

명세서 자동 읽기만 Claude 열쇠가 따로 필요하다(위 참고). 열쇠를 넣지 않으면 그
기능은 화면에서 아예 빠지고, 카드 내역은 기둥에 적으면서 `지출 형식`을 카드로
고르는 방식으로 쌓인다.
